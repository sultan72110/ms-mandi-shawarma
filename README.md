# M.S Mandi & Shawarma — Restaurant Website

Responsive React + Vite website for M.S Mandi & Shawarma (Group of Miskeen), Charminar, Hyderabad.

## Run locally
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed by Vite.

## Included
- Dark charcoal and amber-gold restaurant theme
- M.S logo emblem and branding
- Menu categories: mandi, shawarma & wraps, seafood, starters, broasted chicken, burgers & pizza, gravies & breads, desserts & drinks, add-ons
- Search, category filters and demo basket interactions
- Contact details, map-friendly address, phone call link, and Zomato ordering links
- Responsive layout for desktop and mobile
